# Support

ContextLease is an alpha-stage open-source project maintained on a
best-effort basis.

- Use GitHub Issues for reproducible bugs and scoped feature requests.
- Use the issue forms and remove credentials or real prompt content.
- Use GitHub's private **Report a vulnerability** flow for security reports.
- Questions about integration should include the ContextLease version,
  language binding, operating system, native ABI version, and a minimal
  synthetic configuration.

There is no guaranteed response-time SLA. Production users should pin an exact
version and validate upgrades against their own conformance fixtures.
